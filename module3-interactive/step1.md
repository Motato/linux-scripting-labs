# Read Command | Comando Read

**Example | Ejemplo:**
You can ask the user for specific hardware configurations.
> Puedes pedirle al usuario configuraciones de hardware específicas.

```bash
read -p "Enter target laptop model (e.g., ThinkPad P14s): " MODEL
echo "Deploying script to: $MODEL"
```{{exec}}
