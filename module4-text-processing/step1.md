# AWK

AWK treats text like columns.
> AWK trata el texto como columnas.

**Example | Ejemplo:**
```bash
echo "Oct2025 Half-Marathon 1:56:48" | awk '{print "Race Time: " $3}'
```{{exec}}

### Challenge | Reto
Use AWK to print only the second word of a string.
> Usa AWK para imprimir solo la segunda palabra de una cadena.
